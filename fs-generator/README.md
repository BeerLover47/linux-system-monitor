# 📁 File & Directory Generator (`fs-generator`)

Параметрический генератор вложенных каталогов и файлов со случайным наполнением и контролем размера.

---

## 🚀 Использование

```bash
./main.sh <путь> <кол-во_папок> <буквы_папок> <кол-во_файлов> <буквы_файлов.расширение> <размер>
```

### Пример запуска:
```bash
./main.sh /tmp/test 4 az 5 az.az 3kb
```

* `/tmp/test` — базовый путь создания структуры.
* `4` — количество создаваемых подкаталогов.
* `az` — список символов для генерации имён папок (минимум 4 символа в итоге: `azaa`, `azab`...).
* `5` — количество файлов в каждом созданном каталоге.
* `az.az` — список символов для имени файла и его расширения (до точки имя, после — расширение).
* `3kb` — размер каждого файла (поддерживаются единицы `kb`, `Mb` до 100 Кб).

Все созданные пути, даты и размеры автоматически фиксируются в `file.log`.

---

## ⚙️ Под капотом

* **Быстрое выделение места (`fallocate`):**  
  Скрипт использует системный вызов `fallocate(2)` для мгновенного резервирования блоков на диске без физической перезаписи нулями. Это сохраняет ресурс накопителя и работает в разы быстрее, чем `dd`:
  ```bash
  fallocate -l "${size}K" "$filepath" 2>/dev/null || truncate -s "${size}K" "$filepath"
  ```
* **Паттерн генерации имён:**  
  Если в маске передано меньше 4 символов (например, `az`), скрипт дополняет имя повторяющимся первым символом, сохраняя алфавитный порядок сортировки.
* **Валидация аргументов:**  
  Строгая проверка входных параметров через расширенные регулярные выражения Bash (ERE) с изолированным модулем `validate.sh` (паттерн Guard Clauses).
