## 💡 О проекте

Этот репозиторий я создал в ходе прохождения проекта **DO4 (Linux Monitoring v2.0)** в «Школе 21».

Основная задача проекта — погрузиться во внутреннее устройство Linux: управление файловыми системами, потоковая обработка логов, сетевое нагрузочное тестирование и построение отказоустойчивой системы мониторинга инфраструктуры.

Вместо написания обычных монолитных bash-скриптов я спроектировал модульную архитектуру с защитными барьерами (Guard Clauses), строгой валидацией аргументов регулярными выражениями (ERE) и защитой ядра от исчерпания дискового пространства.

В финальных частях проекта развернут полный стек наблюдаемости (**Prometheus + Node Exporter + Grafana**), проведены стресс-тесты CPU, RAM, диска и сети через `iperf3`, а также написан собственный легковесный Bash-экспортер метрик, отдающий телеметрию по протоколу Prometheus через Nginx.

## 🏛 Архитектурные принципы

При разработке скриптов я придерживался трёх главных правил:

1. **Модульная декомпозиция:**  
   Каждая задача разбита на изолированные подключаемые модули:
   - `main.sh` — единая точка входа, проверка количества аргументов и связывание логики.
   - `validate.sh` — защитные барьеры и валидация через регулярные выражения (ERE).
   - `generator.sh` / `clean.sh` / `filter.sh` — вычислительное ядро алгоритмов.
   - `create.sh` — взаимодействие с диском и системными вызовами ядра.

2. **Защита от сбоя файловой системы (Zero-Crash):**  
   Любые операции аллокации файлов контролируют остаток дискового пространства через `df --output=avail -m /`. Если на диске остается $\le 1024$ Мб, скрипты немедленно завершают работу во избежание kernel panic или повреждения системных файлов хоста.

3. **Независимость от рабочего каталога:**  
   Все скрипты корректно определяют свой физический путь через `${BASH_SOURCE[0]}` и могут запускаться из любой директории:
   ```bash
   DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
   source "$DIR/validate.sh"
   ```

## 📋 Обзор частей проекта (Part 01 – 09)

| Часть | Модуль | Назначение | Ключевые технологии и утилиты |
|:---:|:---|:---|:---|
| **01** | **Генератор файлов** | Создание файловой структуры с именами по алфавитной маске (`az_DDMMYY`), фиксированным весом в Кб и ведением журнала `file.log`. | Bash, ERE, `fallocate`, `df --output=avail` |
| **02** | **Засорение ФС** | Создание до 100 папок со случайным числом файлов до 100 Мб в случайных каталогах ОС до остатка $\le 1$ Гб. Замер времени выполнения. | Bash, `$RANDOM`, `shuf`, замер времени |
| **03** | **Очистка ФС** | Три алгоритма очистки системы: по лог-файлу, по дате/времени создания (`find -newermt`), по маске имени (`*_DDMMYY`). | `find`, Process Substitution, `read` |
| **04** | **Генератор логов** | Генерация 5 файлов веб-логов Nginx в Combined Log Format со случайными IP, HTTP-кодами, методами и строго возрастающим временем Unix Epoch. | Bash, Combined Log Format, Unix Epoch |
| **05** | **Анализ логов в awk** | Высокопроизводительный потоковый парсинг логов Nginx через `awk` (сортировка по кодам, уникальные IP, фильтрация ошибок 4xx/5xx). | `awk`, `sort -k9,9n`, Zero-Fork валидация `compgen` |
| **06** | **GoAccess аналитика** | Визуализация веб-трафика: интерактивный терминальный TUI и генерация статического автономного HTML-дашборда. | GoAccess, Chart.js, HTML-отчёт |
| **07** | **Prometheus & Grafana** | Развертывание стека мониторинга на виртуальной машине, сбор метрик с Node Exporter, кастомный дашборд с 4 панелями и TUI-меню тестов. | Prometheus, Node Exporter, Grafana, PromQL, `stress` |
| **08** | **Дашборд и тест iperf3** | Официальный дашборд Node Exporter (ID 13978), сетевое нагрузочное тестирование через `iperf3` между машинами, анализ трафика Rx/Tx. | Grafana, `iperf3`, сетевой стек Linux, PromQL |
| **09** | **Свой Bash-экспортер** | Написание собственного демона сбора метрик (CPU, RAM, Disk) в формате Prometheus Exposition 0.0.4, атомарная подмена через `mv` и раздача через Nginx. | Bash, Prometheus Format, Nginx, `rename(2)` |

## 🛠 Технологический стек

* **Окружение:** Ubuntu 24.04 LTS, Bash 5.2+, POSIX utilities
* **Системные утилиты:** `awk`, `sed`, `sort`, `find`, `fallocate`, `truncate`, `df`, `date`
* **Нагрузочное тестирование:** `stress`, `iperf3` (клиент-серверное сетевое тестирование)
* **Анализ веб-логов:** GoAccess, Combined Log Format
* **Мониторинг и визуализация:** Prometheus, Node Exporter, Grafana, PromQL
* **Веб-сервер:** Nginx (раздача метрик `/metrics` и статических HTML-отчётов)
