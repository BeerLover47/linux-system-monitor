# Linux Monitoring v2.0 (DO4)

Комплексный проект по автоматизации системного администрирования, генерации и очистке тестовых данных, анализу серверных журналов (Nginx/Apache), мониторингу инфраструктуры и визуализации метрик в стеке **Prometheus + Node Exporter + Grafana** в рамках образовательной программы School 21.

## 🏛 Архитектурные стандарты (Chapter III)

1. **Модульность:** Сценарии не пишутся монолитными простынями. Вся логика разбита на подключаемые модули:
   ```
   01/
   ├── main.sh       # Точка входа (валидация $#, импорт, координация)
   ├── validate.sh   # Проверка типов параметров и граничных условий
   ├── generator.sh  # Алгоритмы конструирования имён
   └── create.sh     # Работа с диском, fallocate, контроль свободного места
   ```
2. **Безопасное подключение модулей:** Независимость от директории вызова через `${BASH_SOURCE[0]}`:
   ```bash
   DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
   source "$DIR/validate.sh"
   ```
3. **Безопасность диска:** Мониторинг свободного места через `df --output=avail -m /` с аварийной остановкой при остатке $\le 1024$ Мб во избежание сбоя хостовой ОС.

## 🚀 Быстрый запуск

### Запуск Part 1 (Генератор файлов):
```bash
# Синтаксис: main.sh <путь> <кол-во_папок> <буквы_папок> <кол-во_файлов> <буквы_файлов> <размер>
bash 01/main.sh /tmp/test_dir 4 az 5 az.az 3kb
```
*Результат:* Будут сгенерированы 4 вложенные папки, в каждой по 5 файлов размером 3 Кб, а пути зафиксированы в `file.log`.
