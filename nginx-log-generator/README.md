# 🌐 Nginx Synthetic Log Generator (`nginx-log-generator`)

Генератор тестовых логов веб-сервера Nginx в стандарте **Combined Log Format** для отладки парсеров и систем аналитики.

---

## 🚀 Использование

```bash
./main.sh
```

Скрипт генерирует 5 файлов логов: `nginx_1.log` ... `nginx_5.log` (от 100 до 1000 строк в каждом).

* Логи охватывают 5 последовательных дней с хронологической сортировкой записей внутри каждого дня.
* Случайные валидные IPv4-адреса.
* Разнообразные коды ответа HTTP (200, 201, 400, 401, 403, 404, 500, 501, 502, 503).
* Различные методы (`GET`, `POST`, `PUT`, `DELETE`), URL-пути, рефереры и реалистичные User-Agent браузеров.

---

## ⚙️ Под капотом

* **Спецификация Combined Log Format:**  
  Каждая строка строго соответствует стандарту Nginx:
  ```text
  $remote_addr - $remote_user [$time_local] "$request" $status $body_bytes_sent "$http_referer" "$http_user_agent"
  ```
  *Пример строки:*
  ```text
  198.51.100.23 - - [17/Oct/2026:14:22:05 +0300] "GET /api/v1/users HTTP/1.1" 200 1420 "https://example.com" "Mozilla/5.0..."
  ```
* **Хронологический порядок:**  
  Временные метки формируются с инкрементом случайных секунд от начала дня, гарантируя строгую монотонность времени без нарушений временной шкалы.
* **Массивы эмуляции трафика:**  
  Используются встроенные массивы Bash для формирования реалистичных комбинаций запросов и статус-кодов.
