# 🧹 File System Cleaner (`fs-cleaner`)

Многорежимная утилита безопасной очистки файловой системы после стресс-тестов и генерации файлов.

---

## 🚀 Использование

```bash
./main.sh <режим_очистки>
```

Поддерживаются 3 режима работы:

### Режим 1: Очистка по лог-файлу
Утилита последовательно читает пути из `file.log`, созданного генератором, и удаляет указанные объекты.
```bash
./main.sh 1
```

### Режим 2: Очистка по дате и времени создания
Запрашивает стартовое и конечное время в формате `YYYY-MM-DD HH:MM` и удаляет всё, что было создано в этом диапазоне:
```bash
./main.sh 2
# Ввод:
# Start time (YYYY-MM-DD HH:MM): 2026-10-17 12:00
# End time   (YYYY-MM-DD HH:MM): 2026-10-17 12:30
```

### Режим 3: Очистка по маске имени
Удаляет файлы и каталоги, чьи имена соответствуют переданному регулярному выражению (например, буквы маски с датой в конце):
```bash
./main.sh 3
# Ввод:
# Mask (e.g. az_171026): az_171026
```

---

## ⚙️ Под капотом

* **Безопасность (`Safety Barriers`):**  
  Скрипт проверяет удаляемые пути и никогда не трогает критические системные каталоги (`/bin`, `/sbin`, `/usr`, `/etc`, `/sys`, `/proc`).
* **Точный поиск через `find`:**  
  В режиме 2 поиск выполняется по временным меткам `newerXY`:
  ```bash
  find / -type f -newermt "$start_time" ! -newermt "$end_time" -delete 2>/dev/null
  ```
* **Изоляция в Process Substitution:**  
  Чтение лог-файла выполняется через конструкцию `while IFS= read -r line; do ... done < <(awk ... "$log_file")`, что исключает создание дочернего подоболочечного процесса (subshell) и сохраняет переменные окружения.
