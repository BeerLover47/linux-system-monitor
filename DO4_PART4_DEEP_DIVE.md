## 1. Паспорт задания и требования Школы 21

Цель модуля — синтетическая генерация реалистичных веб-журналов сервера Nginx для их последующей обработки утилитами потокового анализа (`awk` в Part 5) и визуализатором (`goaccess` в Part 6).

### Требования спецификации:
1. **5 отдельных файлов логов:** каждый файл соответствует **одному дню**.
2. **Формат:** строго **Combined Log Format**.
3. **Количество записей:** случайное число от **100 до 1000** строк на каждый день.
4. **Хронология времени:** в рамках каждого дня временные метки должны идти **строго по возрастанию**.
5. **IP-адреса:** валидные IPv4-адреса хостов (без некорректных значений вроде `999.x.x.x`).
6. **Коды ответа (HTTP Status Codes):** строго из набора 10 кодов:
   * `200` — OK
   * `201` — Created
   * `400` — Bad Request
   * `401` — Unauthorized
   * `403` — Forbidden
   * `404` — Not Found
   * `500` — Internal Server Error
   * `501` — Not Implemented
   * `502` — Bad Gateway
   * `503` — Service Unavailable
7. **Обязательные комментарии:** скрипт обязан содержать комментарии с описанием значения каждого из 10 кодов ответа.
8. **HTTP-методы:** строго из набора: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
9. **User-Agent:** строго из набора:
   * `Mozilla`
   * `Google Chrome`
   * `Opera`
   * `Safari`
   * `Internet Explorer`
   * `Microsoft Edge`
   * `Crawler and bot`
   * `Library and net tool`

## 2. Спецификация Combined Log Format

Стандарт Combined Log Format формируется следующей структурой:
```text
$remote_addr - $remote_user [$time_local] "$request" $status $body_bytes_sent "$http_referer" "$http_user_agent"
```

Пример сгенерированной строки:
```text
36.105.158.92 - - [23/Sep/2026:00:00:45 +0300] "GET /static/style.css HTTP/1.1" 501 3860 "https://yandex.ru" "Mozilla"
```

| Поле в логе | Номер колонки в `awk` | Значение в генераторе | Назначение |
|---|---|---|---|
| `$1` | `$1` | `36.105.158.92` | IPv4 адрес клиента |
| `$2` | `$2` | `-` | Идентификатор RFC 1413 (всегда `-`) |
| `$3` | `$3` | `-` | Авторизованный пользователь (всегда `-`) |
| `$4` | `$4` | `[23/Sep/2026:00:00:45` | Дата и время запроса (открывающая скобка) |
| `$5` | `$5` | `+0300]` | Часовой пояс (закрывающая скобка) |
| `$6` | `$6` | `"GET` | Метод HTTP с открывающей кавычкой |
| `$7` | `$7` | `/static/style.css` | Запрошенный URI |
| `$8` | `$8` | `HTTP/1.1"` | Протокол с закрывающей кавычкой |
| `$9` | `$9` | `501` | **Код состояния HTTP** |
| `$10` | `$10` | `3860` | Количество переданных байт |
| `$11` | `$11` | `"https://yandex.ru"` | HTTP Referer |
| `$12..$NF` | `$12+` | `"Mozilla"` | User-Agent клиента |

## 4. Анатомический разбор модулей

### 4.1. `validate.sh` (Защитный барьер)
```bash
#!/bin/bash

validate_arg() {
  if [ "$#" -ne 0 ]; then
    echo "Error: Too many arguments" >&2
    exit 1
  fi
}
```
* **Guard Clause:** Скрипт не принимает параметров. Если передано $\ge 1$ аргументов, скрипт немедленно аварийно завершается с кодом возврата `1` и сообщением в поток `stderr` (`>&2`).

### 4.2. `generator.sh` (Генератор данных и логов)
```bash
#!/bin/bash

methods=("GET" "POST" "PUT" "PATCH" "DELETE")
answers=("200" "201" "400" "401" "403" "404" "500" "501" "502" "503")
agents=("Mozilla" "Google Chrome" "Opera" "Safari" "Internet Explorer" "Microsoft Edge" "Crawler and bot" "Library and net tool")
urls=("/static/style.css" "/index.html" "/contacts" "/login" "/about")
referers=("-" "https://yandex.ru" "https://google.com")

generate_ip() {
    ip="$(( RANDOM % 254 + 1 )).$(( RANDOM % 256 )).$(( RANDOM % 256 )).$(( RANDOM % 254 + 1 ))"
    echo "$ip"
}

generate_log() {
  local day="$1"
  local file="$2"
  > "$file"

  local count=$(( RANDOM % 901 + 100 ))
  local current_time=$(date -d "today - $(( 6 - day )) days 00:00:00" +%s)
  local i
  for (( i=0; i < count; i++ )); do
    current_time=$(( current_time + (RANDOM % 55 + 5)))
    log_date=$(LC_ALL=C date -d "@$current_time" +"%d/%b/%Y:%H:%M:%S %z")
    ip=$(generate_ip)
    method=${methods[RANDOM % ${#methods[@]}]}
    url=${urls[RANDOM % ${#urls[@]}]}
    status=${answers[RANDOM % ${#answers[@]}]}
    bytes=$(( RANDOM % 5000 + 100 ))
    referer=${referers[RANDOM % ${#referers[@]}]}
    agent=${agents[RANDOM % ${#agents[@]}]}
    
    echo "$ip - - [$log_date] \"$method $url HTTP/1.1\" $status $bytes \"$referer\" \"$agent\"" >> "$file"
  done
}
```

#### Ключевые алгоритмические узлы:
1. **Генерация IPv4:**
   - `$(( RANDOM % 254 + 1 ))`: остаток от деления на 254 дает диапазон `0..253`. Прибавление `1` дает диапазон `1..254`. Это исключает адреса `0.x.x.x` и бродкаст `255.x.x.x`.
   - Внутренние два октета генерируются через `$(( RANDOM % 256 ))` (диапазон `0..255`).
2. **Счетчик строк от 100 до 1000:**
   - `$(( RANDOM % 901 + 100 ))`: остаток от деления на 901 дает `0..900`. Прибавление 100 дает строго диапазон `100..1000`.
3. **Строгая хронология времени (Strict Chronology):**
   - Точка отсчета: полночь текущего дня минус смещение в секундах Unix Epoch (`date -d "..." +%s`).
   - На каждом шаге к `current_time` прибавляется положительное смещение `(RANDOM % 55 + 5)` секунд (от 5 до 59 сек). Это делает время гарантированно строго возрастающим без риска инверсий.
4. **Локаль даты (`LC_ALL=C`):**
   - Обеспечивает строгие английские названия месяцев (`Sep`, `Oct`) независимо от системной локали хоста.
5. **Случайная выборка элементов массива:**
   - `${methods[RANDOM % ${#methods[@]}]}`: индекс выбирается в диапазоне от `0` до `длина - 1`.

### 4.3. `main.sh` (Точка входа и диспетчер)
```bash
#!/bin/bash

#200 — OK (успешный запрос)
#201 — Created (успешно создан новый ресурс)
#400 — Bad Request (синтаксическая ошибка в запросе клиента)
#401 — Unauthorized (требуется аутентификация)
#403 — Forbidden (доступ запрещен сервером)
#404 — Not Found (запрашиваемый ресурс не найден)
#500 — Internal Server Error (внутренняя непредвиденная ошибка сервера)
#501 — Not Implemented (сервер не поддерживает функционал для обработки запроса)
#502 — Bad Gateway (сервер-шлюз получил недопустимый ответ от вышестоящего сервера)
#503 — Service Unavailable (сервер временно перегружен или на техработах)

DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$DIR/validate.sh"
source "$DIR/generator.sh"

validate_arg "$@"

for day in {1..5}; do
  generate_log "$day" "$DIR/nginx_${day}.log"
done
```

## 5. Системные грабли и ловушки Bash

### 1. Ловушка `bad substitution` (пробел перед скобкой массива)
* **Симптом:** `bash: ${methods [0]}: bad substitution`.
* **Причина:** В Bash при обращении к элементу массива `${array[index]}` пробел между именем массива и открывающей скобкой `[` недопустим. Интерпретатор не воспринимает пробельную конструкцию как массив.
* **Решение:** Скобка обязана примыкать к имени: `${methods[index]}`.

### 2. Ловушка перевода строки перед перенаправлением (`>>`)
* **Симптом:** Скрипт выводит 1000 строк текста на экран терминала, а лог-файл остается пустым или содержит нули.
* **Причина:**
  ```bash
  echo "$ip - - [...]"
  >> "$file"
  ```
  В Bash перевод строки является терминатором команды. Первая строка выполняет `echo` в `stdout`, а вторая строка запускает пустую операцию перенаправления.
* **Решение:** `>> "$file"` должно находиться на той же строке: `echo "..." >> "$file"`.

### 3. Ловушка системной локали (`date +%b` vs `LC_ALL=C`)
* **Симптом:** Парсеры логов (`awk`, `goaccess`) падают с ошибками разбора даты на машинах с русскоязычной локалью (`ru_RU.UTF-8`).
* **Причина:** Стандартный `date +%b` выводит русские сокращения месяцев (`окт`, `сен`), что нарушает стандарт RFC Combined Log Format.
* **Решение:** Всегда принудительно задавать локаль `C` при форматировании даты: `LC_ALL=C date ...`.

### 4. Инверсия логики Guard Clause (`-eq 0` vs `-ne 0`)
* **Симптом:** При запуске без аргументов скрипт сразу падает с ошибкой `Too many arguments`.
* **Причина:** Ошибка мышления «пальцы быстрее мысли»: проверка на `$# -eq 0` вместо `$# -ne 0`.
* **Решение:** При защите от лишних аргументов проверяется неравенство нулю (`[ "$#" -ne 0 ]`).

### 5. Массив `${arr[@]}` vs элемент `${arr[idx]}`
* **Симптом:** В лог-файл попадает строка вида `"GET POST PUT PATCH DELETE /index.html HTTP/1.1" 200 201 400 401...`.
* **Причина:** Использование символа `@` склеивает все элементы массива в одну строку.
* **Решение:** Использование целочисленного индекса `${arr[RANDOM % ${#arr[@]}]}`.
