# ⚡ Stream Log Analyzer (`nginx-log-analyzer`)

Высокоскоростной потоковый анализатор логов веб-сервера Nginx на базе `awk`. Обрабатывает гигабайтные дампы за один проход ($O(N)$) без раздувания оперативной памяти.

---

## 🚀 Использование

```bash
./main.sh <режим_анализа>
```

Утилита автоматически находит сгенерированные логи в `../nginx-log-generator/` и поддерживает 4 режима:

| Режим | Описание вывода |
|:---:|:---|
| `./main.sh 1` | Все записи логов, отсортированные по коду ответа HTTP |
| `./main.sh 2` | Список всех уникальных IP-адресов клиентов |
| `./main.sh 3` | Все запросы, завершившиеся ошибкой (статусы `4xx` и `5xx`) |
| `./main.sh 4` | Все уникальные IP-адреса, с которых происходили ошибочные запросы |

---

## ⚙️ Под капотом

* **Потоковая обработка через AWK:**  
  Вместо медленных цепочек `grep | cut | sort | uniq`, создающих несколько подпроцессов на строку, вся предикатная фильтрация выполняется напрямую встроенным движком `awk`:
  ```bash
  # Режим 3: Ошибки 4xx и 5xx
  awk '$9 ~ /^[45][0-9]{2}$/' "$@"
  ```
* **Хеш-таблицы в памяти (Дедупликация на лету):**  
  Для нахождения уникальных IP-адресов используются ассоциативные массивы `awk`:
  ```bash
  awk '{ if (!seen[$1]++) print $1 }' "$@"
  ```
  Это позволяет получать уникальные IP без предварительного запуска тяжелого `sort` по всему файлу.
* **Сортировка строго по числовому столбцу:**  
  В режиме 1 используется `sort -k8,8n` (или по соответствующей позиции поля статуса), что исключает ложную лексикографическую сортировку строк.
