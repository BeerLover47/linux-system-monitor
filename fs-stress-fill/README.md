# 💾 Storage Stress Filler (`fs-stress-fill`)

Утилита стресс-тестирования накопителя: генерирует структуру вложенных файлов и папок в случайных директориях системы до достижения порога свободного места в 1 Гб.

---

## 🚀 Использование

```bash
./main.sh <буквы_папок> <буквы_файлов.расширение> <размер_файла>
```

### Пример запуска:
```bash
./main.sh az az.az 3Mb
```

* `az` — символы для имён папок.
* `az.az` — символы для имени и расширения файла.
* `3Mb` — размер каждого создаваемого файла (до 100 Мб).

По завершении (при остатке $\le$ 1 Гб) утилита выводит:
* Время начала и окончания работы.
* Общее время выполнения теста.
* Полный отчёт обо всех созданных файлах в `file.log`.

---

## ⚙️ Под капотом

* **Надёжный парсинг `df`:**  
  Скрипт проверяет свободное место на корневом разделе через `df -k /`. Чтобы длинные имена блочных устройств (например, в LVM или NVMe) не сдвигали столбцы вывода, используется POSIX-совместимый синтаксис:
  ```bash
  free_kb=$(df -k / | awk 'NR==2 {print $(NF-2)}')
  ```
* **Защита от переполнения (1 GB Barrier):**  
  Перед каждой итерацией проверяется порог: если `free_kb <= 1048576`, цикл немедленно прерывается с кодом возврата `0`.
* **Замер времени выполнения:**  
  Точный расчет затраченного времени в секундах через сравнение временных меток `$SECONDS` или `date +%s`.
